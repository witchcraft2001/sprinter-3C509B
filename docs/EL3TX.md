# EL3TX

`EL3TX.EXE` отправляет ограниченную серию Ethernet II кадров через физический
TPO datapath 3C509B. Утилита предназначена для стендовой проверки и входит
только в диагностический IMG.

```text
EL3TX [-v] [-s 0|1] [-p #100..#1F0] [-b AUTO|#200..#3E0]
      -d MAC [-t #0600..#FFFF] [-l 14..1514]
      [-f 00|FF|55|AA|INC] [-n 1..100] [-w 1..10000]
```

По умолчанию: EtherType `#88B5`, входная длина 60, шаблон `INC`, один кадр и
тайм-аут 10000. `-w` задаёт число квантов ожидания `CYCLES21`, а не точные
миллисекунды: один квант занимает примерно 1–6 мс в поддерживаемом диапазоне
частот Sprinter. `-d` обязателен.

Source MAC всегда берётся из EEPROM карты. Длина в TX preamble равна
`max(input_length,60)`. Короткий кадр дополняется нулями до 60 байт, затем FIFO
дополняется нулями до DWORD; эти служебные DWORD-байты в сеть не отправляются.
В режиме `INC` номер кадра добавляется к начальной фазе payload, поэтому burst
можно проверить на потерю, дублирование и перестановку.

Успех заканчивается строкой `RESULT OK`. Ошибка печатает stage, подробный EL3
код, waitq, base и status, затем `RESULT FAIL code=N`. Код 20 означает конечный
link timeout. DSS exit code при этом следует общей классификации из `specs.md`
(1 — аргументы, 2 — оборудование, 3 — timeout/network, 5 — DSS/память).
При любом исходе выполняются `EL3.DONE` и освобождение DSS-страницы.
