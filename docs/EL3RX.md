# EL3RX

`EL3RX.EXE` принимает ограниченное число Ethernet II кадров через физический
TPO datapath 3C509B. Утилита входит только в диагностический IMG.

```text
EL3RX [-v] [-x] [-s 0|1] [-p #100..#1F0]
      [-b AUTO|#200..#3E0] [-n 1..100] [-w 1..10000]
```

По умолчанию принимается один кадр с тайм-аутом 10000 квантов `CYCLES21`.
Один квант — примерно 1–6 мс, это не точный миллисекундный интерфейс. RX filter
остаётся `individual+broadcast`; чужой unicast не должен попадать программе.

Для каждого кадра выводятся source/destination MAC, EtherType, длина без FCS и
software IEEE CRC32 ровно этих байтов. `-x` добавляет полный 16-байтовый
hex/ASCII dump. Успешное чтение потребляет пакет ровно одним `RX_DISCARD`.

Успех заканчивается `RESULT OK`. При timeout или аппаратной ошибке печатается
`RESULT FAIL code=N` с подробным EL3-кодом. DSS exit code использует общую
классификацию из `specs.md` (timeout/network — 3). `EL3.DONE` и освобождение
DSS-страницы выполняются и после ошибки.
