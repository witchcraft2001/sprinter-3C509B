# Что нужно сделать и прислать

Это не форма для программиста. Ниже — простой порядок действий для человека,
который запускает образ Sprinter и фотографирует экран.

## Сначала собрать образ

В терминале, из корня репозитория, выполнить:

```sh
make clean
make build
make test-host
make package
make image
```

Нужный образ — файл:

```text
distr/sprinter-3c509b.img
```

Именно этот `.img` нужно передать MAME или записать на рабочий диск Sprinter.
Не запускайте файлы из `build/` напрямую в MAME.

Если сборка завершилась ошибкой, пришлите весь текст ошибки и остановитесь.
Если всё хорошо, пришлите последние строки `make test-host` и результат:

```sh
shasum -a 256 distr/sprinter-3c509b.img
```

В Linux вместо `shasum` можно выполнить:

```sh
sha256sum distr/sprinter-3c509b.img
```

## Первый запуск в MAME

Из корня репозитория выполнить:

```sh
MAME_3C509B_SLOT=1 tools/3com.sh
```

Это запускает Sprinter с картой 3C509B в ISA slot 1 и образом
`distr/sprinter-3c509b.img`. Если проверяется slot 0, закрыть MAME и запустить:

```sh
MAME_3C509B_SLOT=0 tools/3com.sh
```

Launcher включает клавиатуру Sprinter, но не включает захват мыши: курсор
остаётся доступен для перемещения, масштабирования и закрытия окна macOS. Если
окно MAME уже было открыто старым скриптом, его нужно закрыть полностью и
запустить заново. Скрипт использует отдельный каталог `.mame-cfg`, поэтому
старый `cfg/sprinter.cfg` не должен отключать клавиатуру.

После загрузки DSS ввести:

```text
EL3INFO -v -s 1 -p #110 -b AUTO
```

Для slot 0 в команде заменить оба `1` на `0`.

Оба slot с `AUTO`, все явные базы и отсутствие карты в slot 1 уже подтверждены;
повторять их не нужно. Следующая проверка — отсутствие карты в slot 0. Закройте
MAME и запустите:

```sh
MAME_3C509B_SLOT=0 MAME_3C509B_CARD=absent tools/3com.sh
```

После загрузки DSS выполните:

```text
EL3INFO -s 0 -p #110 -b AUTO
```

Нормальный результат заканчивается строкой:

```text
RESULT OK
```

Перед этой строкой должны быть `PRODUCT=9550`, `MFG=6D50`, `MAC=...` и
`CHECKSUM=...`. MAC не нужно угадывать — перепишите тот, который показал экран.

Для снимка нажмите Left Ctrl+Delete, затем F12 (на Mac иногда Fn+F12), затем
ещё раз Left Ctrl+Delete, чтобы вернуть ввод в Sprinter. Нужен один снимок, на
котором видны команда, баннер, строки `[E0]`–`[E5]` и `RESULT OK`.

## Остальные команды с установленной картой

В каждом slot выполнить следующие команды по очереди, перезапуская MAME между
slot 0 и slot 1:

```text
EL3INFO -s N -p #110 -b #200
EL3INFO -s N -p #110 -b #300
EL3INFO -s N -p #110 -b #3E0
EL3EEP -s N -p #110
```

Здесь `N` — номер проверяемого slot (`0` или `1`). Для трёх `EL3INFO` ожидается
`RESULT OK` и соответственно `IO=0200`, `IO=0300`, `IO=03E0`.

`EL3EEP` печатает 64 строки EEPROM от `00:` до `3F:`. Для него нужны:

1. снимок начала вывода;
2. снимки середины с перекрытием строк;
3. снимок конца, где видны `3F:`, `[E2]` и `RESULT OK`;
4. обычный текстовый файл со всеми 64 строками без сокращения `...`.

## Проверка отсутствия карты

Закрыть MAME и запустить его без 3C509B:

```sh
MAME_3C509B_SLOT=1 MAME_3C509B_CARD=absent tools/3com.sh
```

В DSS выполнить:

```text
EL3INFO -s 1 -p #110 -b AUTO
```

Ожидается конечная строка `RESULT FAIL code=3`. Программа не должна зависнуть.
При зависании снять видео или несколько снимков с видимым временем ожидания.

## Проверка ошибочных параметров

Эти команды можно выполнить в одном запуске MAME с картой или без неё:

```text
EL3INFO -s 2
EL3INFO -p #101
EL3INFO -p #200
EL3INFO -b #3F0
EL3INFO -h
ISAPROBE
```

Для первых четырёх команд ожидается справка и `RESULT FAIL code=2`. Для `-h`
ожидается справка и `RESULT OK`. Для `ISAPROBE` без параметров — справка и
`RESULT FAIL code=2`. Эти команды не должны обращаться к ISA-карте.

## Что прислать мне

Достаточно одного архива или папки со следующими файлами:

- `build.log` — полный вывод пяти команд сборки в начале этого файла;
- `img.sha256` — результат `shasum -a 256 distr/sprinter-3c509b.img`;
- `mame-version.txt` — вывод `mame -version`;
- `mame-commit.txt` — результат `git -C ../mame rev-parse HEAD`, если рядом
  есть checkout исходников MAME;
- `slot0-auto.png`, `slot1-auto.png` — снимки двух успешных `EL3INFO -v`;
- `slot0-base*.png`, `slot1-base*.png` — снимки трёх временных баз для каждого
  slot;
- `slot0-absent.png` или `slot1-absent.png` — снимок проверки без карты;
- `invalid-args.png` — снимок ошибочных параметров;
- `eeprom-*.png` — снимки полного `EL3EEP`;
- `eeprom.txt` — все 64 строки EEPROM `00..3F`;
- `commands.txt` — точные команды, которые были введены, в том же порядке.

В `commands.txt` также напишите для каждого запуска: `RESULT OK` или точный
`RESULT FAIL code=N`. Не переписывайте ошибку как успех и не удаляйте зависший
или неожиданный вывод.

## Если проверяется настоящая карта

Дополнительно нужны:

- фото карты и её маркировки;
- номер физического Sprinter ISA slot;
- MAC с наклейки;
- фото/скрин `EL3INFO -v`;
- полный `eeprom.txt`.

Сначала запускается только `EL3INFO`, затем `EL3EEP`. EEPROM не записывать,
IRQ не настраивать, неизвестные ISA-порты не сканировать. Если карта или DSS
зависли, прекратить тест, сохранить экран и сообщить точный момент зависания.

Не нужны pcap, сетевой кабель и сетевые команды: на этом этапе сеть ещё не
тестируется.
